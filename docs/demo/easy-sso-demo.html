How to explore

Click Log in, then Connect terminal. Type help in the simulated shell. Use Ctrl+] or AWS workspace to return. Keys 1–6 open EC2, Databases, Sessions, Tunnels, Credentials, and Backup.

Try switching profiles while sessions stay open, editing connections, database IAM setup, credential renewal, and disconnect reviews. ? opens the shortcut guide. Browser-reserved shortcuts have buttons above. In forms, Tab/↑/↓ changes fields, Enter advances, and Ctrl+S saves an edit. Escape cancels; Escape then Tab leaves the workspace.

Backup uses virtual files in memory. Import demo/bookmarks-backup.json to preview an addition and a conflict. Export to a new virtual filename, then import it. No files are read or written.

This single HTML file contains all styles, code, and fixtures. It works when opened directly from disk. There is no backend, AWS sign-in, real shell, tunnel, analytics, browser storage, or external asset. Reload/reset discards changes. Network connections are also blocked by the page's content security policy.

The interface follows the Go app's layout and workflows, but this standalone simulation does not execute the Go UI or verify real AWS behavior. OS terminal windows are unavailable; use Connect terminal.
